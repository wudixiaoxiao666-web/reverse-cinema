# 输出与提示词契约

生成报告、复用模板或二创成稿时使用。字段可合并，不能丢证据、不确定性与连续性交接。

## 分析层

故事表：`场景/节拍｜源时间或样本组｜观察事件｜因果解释（推测）｜价值/信息变化｜证据`。没有人物行动的产品展示可写信息主线，不创造冲突。

镜头卡：

```text
SHOT S01（仅截图则“画面样本 F01”）
源入点–出点 / 时长 / 精度与覆盖：
景别 / 机位高度与角度 / 焦段感：
摄影机运动 / 主体运动（分别写）：
构图、人物位置、前中后景：
Start State → Action → End State：
切入 / 切出及声音交接：
镜头目的（推测）及依据：
证据 / 未知项：
```

连续性表：`SHOT｜角色/衣着｜道具/手｜站位与视线｜画面运动方向/轴线侧｜光线｜下镜承接状态`。

风格表写观察与机制，DNA 表写跨镜规则，不用相同形容词填两张表。

DNA 格式示例（**不是任何参考片的默认结论**）：

`D03｜揭示威胁前 → 先让画外动作声进入，保持当前画面，再切声源 → 形成信息差（效果推测）｜S03/S07 及对应音轨时码｜仅揭示段；无音轨不能确认｜中`

## 提示词层

区分 **风格块**（去内容化）、**占位模板**（填变量后才能执行）、**绑定成稿**（角色/场景/动作/时长确定，完整可粘贴）。不要把未填 `[角色]`、`[地点]` 的模板称为直接可用成稿。

### Global Style Prompt

按 `Visual Medium → Camera → Lens → Composition → Lighting → Color → Texture → Movement → Editing Rhythm → Sound Logic` 写自然语言，仅包含采纳的 DNA。不要包含原片专有姓名、场地、台词、特定物件或原剧情，内容在下层绑定。

无证据的要素不补为原片事实；二创新增选择另标建议。跨镜节奏为全片指导，具体剪辑写执行表。纯文本 Hard Lock 不能保证精确一致。

### 二创绑定与故事

先映射 `原片故事功能（证据）｜新情境/动作｜保留的 DNA｜有意改动及原因`，再给新的一句话与节拍。优先用用户主题；无主题示范时明确写“二创示例”。

绑定表按需包含：稳定角色 ID/外观、地点空间锚点、道具及状态、昼夜/主光方向、画幅/总长、提示词语言。没有参考图不假装已锁定真实身份。

### Temporal Prompt

每片段一个主动作及必要辅助动作。按完成动作所需时间拆分；过密则拆开。时长冲突时给可行压缩/拆分方案，说明取舍。

```text
CLIP C01 | 二创局部时间 0–Xs | 目标时长 Xs | 画幅 | DNA 引用
Start State：人物、道具、空间、姿态的可见起点。
Camera：景别、起始机位、唯一主运镜及速度/停止节点。
Action：谁在何时做什么，明确起止及方向。
Visual Change：动作造成的可见变化，或保持。
End State：可供下镜承接的构图、姿态、道具状态。
Continuity：继承前镜哪些外观、位置、光色、方向，允许的转场。

完整可粘贴提示词：把绑定内容与本镜必要的 Global/Hard Lock
合并为自然语言，避免只写“同上”或要求模型自行读取 DNA ID。
```

需要首尾帧/参考图时列资产，不虚构附件。仅截图且要求运镜时，运镜是二创新设计。方向使用“画面左/右”等参照，移动中用空间锚点解释关系。

### Hard Lock

| 类别 | 锁定项 | 允许变化 | 检查 |
| --- | --- | --- | --- |
| 身份/道具 | 外观、持物手、完整状态 | 剧情明确导致 | 相邻首尾比对 |
| 镜头族 | 焦段感、机位高度、运动逻辑 | DNA 允许的高潮/转场变化 | 镜头卡 |
| 空间 | 相对位置、运动方向、轴线逻辑 | 中性镜头/可见运镜建立新轴 | 连续性表 |
| 视觉 | 主光方向、主色/强调色、纹理 | 有动机的环境/剧情变化 | 同场景比对 |
| 节奏 | 阶段镜长关系、揭示/停顿逻辑 | 明确标记的节拍变化 | 剪辑时间线 |

排除项写具体错误，例如单镜不突然换脸/衣服、主光不无故反向、不追加无动机环绕、道具不瞬间换手。模型无负面提示通道时用自然语言，不杜撰参数，不保证约束必定生效。

### 剪辑与声音表

`时间/片段交界｜画面入出点/转场｜声音进入退出/相对响度｜字幕/字卡｜执行方式`

按已核验能力区分原生生成、参考音轨、后期添加、待验证。无音频功能则同步/混音留后期。精确台词、字幕及品牌文字可列后期叠加，不承诺逐字生成。

## 行为检验用例

1. 三张无时码截图：仅静态分析，声音/镜长/运镜未知；不做全片统计；DNA 不凑数；可提供标为新设计的二创运动。
2. 只有 SRT：给文字层节拍，不推断灯光、焦段或声音表演；字幕时间不当切点。
3. 6 秒循环产品空镜：用信息/注意力变化，不强造人物冲突，关注循环首尾。
4. 快切后长镜的完整短片：保留节奏阶段及例外，不锁死单一镜长。
5. 未指定模型的新题材二创：自然语言，填内容变量，核对首尾与总长，不声称模型特定能力。
6. 新主题要求暖色、原片偏冷：按用户要求说明偏离，更新约束，不同时写冷暖两套硬锁。
